# 个人学习数据与生词本转移

设置中的“跨电脑导入导出个人学习数据”输出 Qonsona format 1 JSON。生词本页可输出当前语言整本或仅选中词本。文件包含词卡卡面、词本成员、SRS 排期和复习设置；个人数据另包含所有语言课程进度、练习/试卷历史、学习时长、自定义阅读与译文。仅选中词本输出其自己的每日计数（有记录时），不携带整门语言的总量与语言级设置。

导出前 `await flushAll()` 等待持久化队列及实际写盘；没有固定延时。输出写入临时文件后 rename。旧 ZIP 完整备份/恢复格式及旧 Qonlang Study manifest 仍保留。

导入首先检查 app/format、大小（32 MiB）、递归深度与节点量、原型键、文件白名单、包 ID、卡键命名空间及一致性、引用、排期、日期、课程和试卷结构。单语生词本不接受另一种语言的文件。个人包内的每个语言都必须在包清单声明。试卷范围、答案和解释检查失败时整体拒绝。阅读 URL 只接受 HTTP/HTTPS。

预览显示来源日期、各语言卡/词本/课程/试卷/文章数量、文件新增/更新/不变数、文字冲突数及缺少的自定义包。选择文件不修改用户目录。预览 token 绑定当前窗口、有效期30分钟和文件 SHA-256；确认时重新读取并检查文件未变化。

确认前再次等待写盘，保存经过验证的 `transfer-pending.json`，重启后在开窗前重新读取本机最新记录并合并。不同 ID 的记录均保留；同一卡采用最后复习时间较新的排期，相同时间保留本机。成员关系取并集；历史试卷按 ID 去重；课程通过/学过状态取并集、成绩和次数取较大值；文本/译文 ID 冲突保留本机。复习配置按其更新时间合并，未提供的语言级设置不会移除本机设置。已删除词本的历史每日记录仍保留。

每日累计计数与学时保守取最大值而不相加。这保证反复导入幂等，但无法准确叠加两台电脑在同一天各自独立进行的学习；这种情况可能低估总量。当前记录没有独立事件ID，不能把快照误当成可无损事件同步。

每次合并把受影响旧文件保存到 `backup-before-import-<时间>-<随机后缀>`，并记录新建文件清单。写入失败时回滚本次已经写入的文件。待处理文件只在成功后删除；异常断电后仍可重新按幂等规则完成。此功能不提供云账户、联网同步或删除传播。

JSON不包含学习包源数据、词典数据库、录音、媒体库及外部音视频文件。另一台电脑应安装相同包ID和词典版本，避免自定义词条ID变化。完整ZIP备份可携带学习包和录音；原媒体文件仍位于外部路径，需另外复制并在视听模块重新添加。跨电脑不能用原机器绝对路径直接播放。缺包时记录保留但课程/源词条能力待装包后恢复。

验证：`npm test -- tests/transfer.test.ts tests/transfer-ipc.test.ts`。文件测试只使用 `os.tmpdir()` 创建的专属临时目录；IPC测试模拟Electron文件对话框和重启动作，不打开真实用户数据。
