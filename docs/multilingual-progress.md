## 语言各自的内容

- 英语：拼写与读音、弱读、冠词与可数性、时体、条件与倒装、搭配；保留英语考试与开放词表。
- 法语：拼读、省音与联诵、性数一致、代词位置、时态与语气；中文释义仍需继续补译和复核。
- 韩语：字母组合、收音及常见音变、语节、助词、敬语、连接词尾、引述与书面表达。
- 西班牙语：重音与拼写、变位、宾语代词、过去时对照、虚拟式触发与语篇结构。
- 阿拉伯语：RTL、字母位置形式、不连写字母、词根与派生式、附着词、双数与破碎复数；使用现代标准阿语内容。
- 俄语：字母、重音与软硬音、格、体、运动动词、分词与副动词；保留 ТРКИ 分级体系。
- 盖尔语：宽窄与弱化、动词首位、介词代词、bi/is、独立式与从属式、动名词和关系结构。

语法识别保留可靠的词形规则，并加入教学例句高亮的精确模式。精确例句命中不能代表可以解析所有同类真实句子。
未解析的词、没有录音的词和没有中文释义的词不伪装成已覆盖。

## 本轮通用修复

- 故事课打开本语言的阅读器，阅读返回相应课程；本文练习从真实正文中的词汇和识别出的语法出题。
- 每课都有可运行测验；俄语首课合并足够的对比项，修复空测验。
- 自测卷题数不足时报告不可用，不静默删掉空节或更改分值权重；中英文选项去重。
- 全量分级词表按声明数量导入，解决默认上限截断大型词表。
- 正文合并词典短语时，语法识别仍能看到短语内部词序。
- 阅读正文保留原文的句间空白，避免分句后将英语、法语、阿拉伯语的相邻句子连写。
- 切换语言时防止旧阅读结果、播放结果、录音保存落到新语言。
- 同一媒体文件用于不同语言时，各有独立字幕、位置和设置。
- 词典在组件初始化时创建状态，避免首次查询详情更新不可靠；无系统语音的盖尔语仍可使用自己的录音。
- 首页打开文章时直接记住文章 ID，避免背景刷新后返回到另一篇。
- 盖尔语数据库按现行查词键刷新，保持词条和例句 ID，补入既有中文翻译并标记机器翻译来源。

新闻逐个实际请求并经过应用的 RSS/Atom 解析器验证，检查时间与结果保存在快照。
修正 RTVE 与 KBS 的旧地址；韩联社旧地址返回 404，暂不列入启用来源。
本机最近一次检查：英语 28/28、法语 14/14、韩语 3/4、西班牙语 3/3、阿拉伯语 18/18、俄语 6/6、盖尔语 6/6。
韩语的东亚日报在首次检查可用，复查请求超时；保留来源，并记录结果而不声称每次都能连通。
版权新闻只保留公开标题与导语，附原文链接；开放全文来源按其许可与署名处理。
网络可用性随站点变化，不把新闻源数量当作教学内容数量。

新增盖尔语说明依据 [LearnGaelic 语法资源](https://learngaelic.scot/grammar/index.jsp)、
[SpeakGaelic 条件句](https://speakgaelic.scot/level/gnothachas/topic/planaichean-is-amasan/section/nam-bithinn)
和 [UHI 语法指南](https://gaelictoolkit.uhi.ac.uk/docs/stiuireadh-gramair.pdf)核对。
新增西班牙语用法参考 [RAE 语气说明](https://www.rae.es/libro-estilo-lengua-espa%C3%B1ola/el-modo-indicativo-o-subjuntivo)。
这些链接是语法参考；应用中的说明、例句和样例读物为自写内容，未复制网站课程。
