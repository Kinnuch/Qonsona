# 收集与学习打卡

本轮收藏为跨语言共享的十二枚学习伙伴，两套各六枚。每天本机日期内真正完成任意一项：读完文章、结束练习、完成课程或结束有作答的复习，即记一次打卡。同一语言、活动类型和内容标识在同一天只保留一条完成事件；重复打开页面不打卡。

课程中自动标为“学过”的旧进度仅用于课程浏览记录，不触发收藏打卡。语法、变形、会话及字母课末尾的“完成本课学习”按钮明确确认完成；当前语言、课程与课必须匹配，且确有非空教学内容才可使用。完成已作答的课程测验也可打卡。同一课的明确完成与课后测验使用同一日内标识，不重复记录。打开故事课或点击“阅读”只导航，返回按钮不计为学习完成。

当天有效学习累计达到 5、15、30 分钟，且已打卡，每个门槛各解锁收藏顺序中的下一枚。达到门槛前完成或达到后再完成都有效。一天最多三个门槛，已有伙伴永久保留；收齐十二枚后仍保留学习记录，不再生成额外伙伴。此策略固定、无抽奖、无付费。

有效奖励时间要求窗口可见且前台，位于阅读、练习、课程、生词本、词典或视听模块，并在最近两分钟有鼠标键盘操作。只播放媒体但没有近期操作不增加奖励时间；首页、收集、统计、语言管理和设置不计时。每十五秒累计，关窗和切换页面先结算；跨本机午夜拆成两天，新日期需要新的真实完成。启动软件本身不产生打卡或奖励。

奖励存在 `stats.json` 的可选 `rewards` 字段，包含参与起点、每日有效秒数、真实完成事件、已领取门槛和已解锁伙伴。旧版本统计只有学习时长，不能证明这些真实完成事件，因此不追溯补发奖励。关闭保存、完整备份和个人学习数据导入导出均保留新字段；旧文件仍可导入。两设备快照合并取每日秒数较大值、完成事件与门槛并集、伙伴按固定编号去重；合并过程不自动补发新奖励，重复导入不会累计或复制收藏。两台设备同日独立学习的时间可能保守低估，不视为实时云同步。

收藏页可查看当前目标、十二枚锁定/解锁状态、伙伴的解锁日期与门槛，并查看最近 31 个打卡日（存储保留全部日记录）。随语言强调色、深浅色与窗口宽度变化；减少动态效果设置关闭解锁动画。

## 阅读题进度转移

个人数据转移增加 `article-quizzes/<packId>.json`，包含文章指纹、当前答案、完成标记和历史作答，不存题目脚本。严格校验答案范围和记录结构；同指纹保留更完整答案及完成状态，历史去重，不同指纹需要重做当前题目。仅词本转移不携带本文练习。学习包与录音仍用完整ZIP，外部文件另行复制。

验证：`tests/rewards.test.ts` 包含精确时长门槛、日内幂等、跨午夜、前台/空闲过滤、旧统计迁移、导入校验/重复合并，以及独立临时目录的真实导出、合并、重载验证。界面和完成事件由整体 Electron 验收检查。
