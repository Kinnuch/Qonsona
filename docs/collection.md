# 收藏、灵墨与寻访（未发布测试）

收藏和排行榜须登录 Qonsona / Qonlang 共享账号。账号、灵墨、语灵、道具、寻访结果与保底都保存在服务器；不同电脑分别登录同一账号即可查看。Qonlang 本地工程仍可离线使用，工程正文和录音不上传。离线也可退出本机账号。

收藏分为「画廊、每日任务、商店、寻访、行囊」。四档语灵称为初识 A、相知 R、珍遇 SR、传颂 SSR。测试池使用用户提供的十二个伙伴，每档三枚；不代表正式素材数量。

## 灵墨与每日任务

有效学习要求窗口可见且在前台，处于阅读、练习、课程、生词本、词典或视听模块，最近两分钟有操作。只播放媒体、首页及收藏浏览不计。客户端每十五秒结算；服务器按账号合并设备的最近在线时间，重叠时间不累加，首次心跳只初始化。

- 每个有效学习分钟获得 2 灵墨，每日最多 120（首 60 分钟）。服务器接受的排行榜时长每日最多 120 分钟；离线、本轮登录前及历史本地时长不追溯领取积分。
- 每日三项目标各 20 灵墨：完成任意学习活动、完成指定板块一、完成指定板块二。默认阅读和复习；当天开始计时或完成活动前可调整一次，两个板块须不同。第一次阅读可完成「任意」与「阅读」，再读文章不能代替复习。
- 星期一至星期日内至少五个不同日期，每日有 10 分钟云端有效学习并完成一个活动，获得一次 80 灵墨周奖励，满足第五日条件即发。补签不参与周奖励。

阅读完成、结束已作答练习、明确完成课程或结束有作答复习产生完成事件。同一天同语言、活动类别与内容只计一次。打开页面、旧「学过」记录和故事课导航不计完成。客户端上报不能证明真人实际学习；服务器限制重放、异常数值与重叠时间。

商店价格：初识语灵 240 灵墨、相知 720、寻访笺 240、续页笺 80。珍遇和传颂只从寻访获得。已拥有语灵不能重复直购。余韵只兑换装饰（微光装裱 20 余韵），不能兑换灵墨或寻访笺。

## 寻访概率与保底

| 档位     | 基础概率 | 重复获得余韵 |
| -------- | -------: | -----------: |
| 初识 A   |      70% |            1 |
| 相知 R   |    24.4% |            3 |
| 珍遇 SR  |       5% |            8 |
| 传颂 SSR |     0.6% |           20 |

连续 19 次未获得珍遇或传颂，第 20 次至少珍遇。连续未获得传颂时，第 76 次传颂概率为 5.6%，之后每次提高 5 个百分点，第 89 次为 70.6%，第 90 次必得传颂。传颂判定优先；非传颂按 70:24.4:5 归一化分配，有珍遇保底时只落入珍遇。各档内三枚测试语灵均匀选择。

学习笺与支持笺余额分开，**共用一套保底**。单次/十次只扣所选来源，余额不足不自动混用。传颂重置两项保底，珍遇只重置珍遇保底。重复语灵保留数量并发余韵，不作为新的独立收藏计入榜单。

服务器在同一 SQLite 事务中扣券并保存结果和保底。网络中断保留原请求编号，重连或重启恢复同一次结果；多设备重放不会重复扣券，界面忽略迟到的旧修订。消费前有确认，失败可重试原交易。

## 续页笺与旧纪念

续页笺库存最多 3 张，可补最近 7 天中未打卡日期，每个当前自然月最多用 2 张。它只补日历，不增加时长、任务、积分或周奖励。

旧版已解锁伙伴保留为纪念，登录后可预览并明确点击「同步旧纪念」，在其他设备查看。它没有灵墨、券、保底或榜单价值；新活动停止旧版 5/15/30 分钟免费解锁。JSON/ZIP 转移仍保留本地学习数据和旧纪念，**不能覆盖云端钱包或导入付费券**。

## 排行榜

支持收藏数量、总时长及各语言时长。收藏数只计不同的新语灵；时长只计登录后服务器接受的在线有效时间，与统计页本地历史可能不同。公开参与默认关闭，可分别启用收藏/时长榜。公开只显示昵称、随机公开编号和榜单数值，不显示登录用户名、付款金额或私有内容。

## 支持券与测试入口

支持券测试定价为每张 6 元、每月待审核与已确认订单合计最多 60 元。当前只有明确标注的模拟订单，**没有真实收款二维码，不应付款**。独立管理员核对订单金额与唯一交易编号才可发券；客户端点击和图片不能直接发券。正式收款默认关闭，实际年龄核验、销售政策和真实支付接入尚未完成。

2026-10-13：服务部署在 mycloud（111.229.26.130）的独立测试数据库。kinnuch.cn 正在 ICP 备案，HTTPS 尚未可用。隔离客户端通过加密 SSH 本地转发访问实际服务器；正式地址固定为 `https://kinnuch.cn/qon-api/v1`，不降级公网 HTTP、不跳过证书。部署位置见 [服务说明](../server/README.md)。

专用测试版须同时开启构建、主进程和服务端测试开关。登录后词典搜索 `kinnuch` 并回车，每账号每测试批次领取 100 学习寻访笺；重复操作不累加。正式构建与生产服务均拒绝赠券。

## 素材与阅读数据

## 验证

`npm run typecheck`、`npm run lint`、`npx vitest run` 验证客户端，`npm run server:test` 验证服务事务、权限、任务、保底、补签和支付。`npm run smoke:accounts` 使用独立临时档案、真实 API 和 Electron 界面；可将 `SMOKE_API_BASE` 设为本地 SSH 转发地址验收云端。
