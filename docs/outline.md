# 大纲（2026-09-23 定稿）

语言学习桌面应用。先做日语，功能参考 [Todaii Japanese](https://japanese.todaiinews.com/)；
程序本体不写死任何语言，以后会扩展到很多语言，也包括从千语集导入的人造语言
（对齐方案见 [qonlang-alignment.md](qonlang-alignment.md)）。

## 从参考站点保留什么

| 参考站点的模块 | 本应用 |
|---|---|
| 主页（真实文章阅读） | 阅读：文章库（等级、主题、来源筛选，隐藏已读）+ 阅读器 |
| 阅读详情 | 振假名 / 罗马音 / 不注音；按 JLPT 等级给词加下划线；点击查词；朗读并高亮当前句；本文词汇表与语法表；本文练习（用这篇的词、读法、语法、句子出题）；双语对照（自己贴的译文） |
| 课程 | 五十音；动词变形、惯用语、JLPT 语法（N5–N1）、会话、民间故事 |
| 词典 | 词汇、汉字、语法、例句；日日词典与中文维基词典（维基词典的释义）；手写查字 |
| 生词本 | 自建词本 + 内置词本（JLPT N5–N1、25 个主题）；已记住 / 不确定 / 未记住；闪卡；间隔重复复习 |
| JLPT 备考 | 按等级自动出题；JLPT 卷面结构的模拟卷（题目不能照搬参考站点和官方真题） |
| 视频 / 播客 | 本地视频、音频配字幕文件；逐句查词、复读、倍速 |
| 个人页 | 统计：连续天数、时长、已学词与语法 |
| 登录、付费、广告、评论 | 不做；单机使用，备份导入导出 |

## 日语的数据来源

JMdict（词典，CC BY-SA 4.0）、KANJIDIC2（汉字，CC BY-SA 4.0）、KanjiVG（笔顺与手写查字的参考笔画，含假名，
CC BY-SA 3.0）、Tatoeba（带中文翻译的例句，CC BY 2.0 FR）、tanos.co.uk 的 JLPT 分级表（CC BY）、
kuromoji.js + IPADIC（分词与读音，Apache 2.0）、Kanjium（声调，可选，CC BY-SA 4.0）、
青空文库的公有领域作品（内置文章、故事课的民间故事）、维基词典（日语版的日语释义、中文版的中文释义，
CC BY-SA，经 kaikki.org 的 wiktextract 抽取；可选，`node scripts/data/wiktionary-ja.mjs` 生成）。朗读用 Windows 自带的日语语音（本机已装 Haruka、Ayumi、
Ichiro、Sayaka）。

### 中文释义（M1 定下的做法）

JMdict 只有英文等释义，没有中文。现在分三层：

1. **常用词与 JLPT 词（23,177 个）**：由 JMdict 英文释义逐义项翻译成中文（开发时批量翻译：
   `scripts/data/mt-batches.mjs split` 切成小份，按 `scripts/data/mt-guide.md` 的规范逐份翻译，
   `merge` 核对义项数后写进 `data/zh/mt-en/`，这份结果入库）。
2. **其余词条**：Tomoshi 开放数据（CC BY-SA 4.0）的中文释义，也是由英文释义翻译、再经模型复核的。
   另外用了它的例句中文翻译、中日同形词对照、汉字中文字义、自他动词配对。
3. 界面上每个词条注明中文释义来自哪一层；机器翻译的例句单独标出。

调研过、没用的：Jitendex 中文版（质量不如上面两份）；中文维基词典「日语」一批（来源不明，疑似转自商业辞典）；
各种来自商业辞典的 Yomitan 词典（没有许可）。中文维基词典「日語」一批是人工写的，许可也合适，
2026-10-08 起作为「维基词典（中文释义）」一栏放在词条下面（另一栏是日语维基词典的日语释义，当作日日词典）。

构建：`npm run data:ja` 下载原始数据到 `.cache/data/`、生成 `resources/data/ja/dict.sqlite`（约 95 MB，不入库）。
