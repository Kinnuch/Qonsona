# 与千语集对齐

千语集用来造语言，Qonsona 用来学语言。作者在千语集里把语言造好、存成项目文件；
学习者把这个文件导入 Qonsona，就得到这门语言的整套学习内容：字母与文字、词典、阅读、
语法、变形练习、会话和复习。

学习软件对千语集项目**只读**，从不写回。

## 一、交换什么：直接读千语集的项目文件

- **输入**：千语集的项目文件 `.laim.json`（schema v1），或千语集「设置」里「导出为一个 CSV」
  导出的整个项目。千语集那边**不需要为学习软件另做导出**。
- **解析用千语集自己的代码**。`scripts/sync-qonlang.mjs` 从千语集仓库取**已提交**的
  `core`、`engine`、`script`、`ipa` 四个目录，拷进 `src/renderer/src/vendor/qonlang/`，
  把 `$lib/` 换成 `$qon/`，并在 `VERSION.json` 里记下提交号。当前快照是
  千语集 0.12.2 @ `21a261f`，共 79 个文件。
- **为什么用快照，不自己重写解析**：学习者看到的屈折形由构形流水线推出来，读音由正字法规则
  转出来，自造文字的写法由文字规则转出来。任何一步自己重写都可能跟千语集算得不一样。
  用同一份代码，学习者看到的就是作者在千语集里看到的。M0 已经验证：Aelith 的短语
  「nöl sen」在学习软件里写成 `ᚾᛜᛚ ᛊᛖᚾ`，每个字都出自它的刻文字形表。
- **为什么不直接引用千语集仓库**：一是千语集渲染层里有 3 个文件跟界面状态缠在一起
  （`core/guide.ts`、`core/tourSteps.ts`、`engine/gloss/resolve.ts`），快照里跳过；
  二是千语集常有没提交的改动，而快照固定在某个提交上，学习软件的行为可以重现。
  要跟进千语集的新版本，跑一次同步脚本、再跑测试即可。
- **垫片**：快照里只有两处引用了千语集界面层的东西，同步时自动生成：
  `core/sealed.ts` 的一段密钥在 `ui/flash.ts`（只取 `FLASH_SEQ` 常量）；
  `core/stressInfo.ts` 要用语素类型的中英文名（只取 i18n 里的 `morphemes.types`）。
- **版本不兼容时**：项目的 `schemaVersion` 比快照里的千语集新，就拒收，并提示先更新学习软件。

## 二、一门语言对应一个学习包

- 一个千语集项目里可以有好几门语言（祖语、子语言……），导入时逐个勾选，每门语言成为一个学习包。
- 包 id 是 `qon-<项目 id 前 8 位>-<语言 id 前 8 位>`。同一个项目的同一门语言再次导入时，
  覆盖的还是这个包。
- 包放在 `%APPDATA%\qonsona\packs\<id>\`，里面有三个文件：`manifest.json`
  （名称、颜色、能力、统计、来源）、`levels.json`（按词频分的级）和 `source.laim.json`（导入时的项目原文）。
- **学习进度（M3 起）按千语集的词条 id、例句 id、短语 id 记**。这些 id 是千语集生成的 UUID，
  不会变。所以作者更新项目、学习者重新导入之后，进度不会丢；被作者删掉的词条，进度留着但不显示。
- 界面的强调色取语言在千语集里的颜色；按钮文字用白色还是深色按对比度自动选。
  自造文字的字体（系统字体或内嵌字体）用千语集的 `ensureScriptFont` 注册。

### 能力怎么从数据推出来（`lib/packs/qonlang/convert.ts`）

| 能力 | 判断依据 |
|---|---|
| 阅读 | 这门语言有例句 |
| 词库（词典、生词本、练习） | 有词条 |
| 字母课 | 有带字形的文字 → 学文字；否则有音位 → 学字母与发音 |
| 词典里「字」那一栏 | 有语素 → 语素；否则有意音文字 → 字形 |
| 语法 | 有这门语言的文档，或者没指定语言的文档 |
| 变形 | 这门语言的词条用到了构形 |
| 会话 | 有短语 |
| 注音 | 词条有 IPA，或正字法写了转 IPA 的规则 → 国际音标；否则有两套以上正字法 → 另一套拼写 |
| 转写 | 有自造文字（可以在「原文 / 自造文字」之间切换） |
| 逐词对译 | 有语素，或者有确认过分析的例句 |
| 词源 | 有词条写了词源来源或中间形式 |
| 视听、考试 | 人造语言都没有 |
| 朗读 | 用系统语音读 IPA，自己的录音优先（见第五节） |

## 三、千语集的数据在学习软件里的用处

| 千语集里的数据 | 学习软件里的用处 | 阶段 |
|---|---|---|
| 词条：词头、词类、义项（多语言释义、语域）、发音、文字写法、屈折形、词源、关系、配图、检视器模块 | 词典的词条卡 | M1 |
| 语素：词根、词缀、异体形、gloss | 词典「语素」页签（日语那边是「汉字」） | M1 |
| 音位表、正字法、字母表顺序、多合字母 | 字母课：字母与发音 | M4 |
| 文字：字形表、字体、音节拼合、竖排 | 字母课：文字；各处都可以切换成用自造文字显示 | M2、M4 |
| 例句：原文、各正字法、文字写法、译文、出处、标签、逐词分析 | 阅读：按出处分成篇章（学习包里排了课时按课）；隔行对译；点击词语查词 | M2 已做 |
| 缩写表 | 隔行对译里 gloss 缩写的说明（悬停看全称） | M2 已做 |
| 短语：分类、译文、发音、变体 | 课程「会话」（按分类分课）；闪卡（学习包里课的短语进内置词本） | M3、M5 已做 |
| 标签、收藏、记号 | 生词本的内置词本：作者收藏的排最前（建议先学），每个标签一本 | M3 已做（记号没用上） |
| 文档（Markdown） | 阅读里各成一篇、当课文；课程「语法」 | M2、M4 已做 |
| 构形：维度、槽位、变体，加上词条的屈折形 | 课程「变形」的变形表；练习里的变形题（给出词和格位，从这个词的几个形里选出对的） | M5 已做 |
| 词条的释义、发音，例句的译文 | 练习：看词选意思、看意思选词、听音选词、看句子选译文（可以只出某一级的词） | M5 已做 |
| 词源、音变规则集、历时阶段 | 词条卡的「历史形式」；练习的「音变」题（看原始语的形式，选出按音变规律推到这门语言的形式，干扰项是推导途中的形式） | M1 起，音变题 M8 已做 |
| 语言颜色、文字字体 | 强调色与字体 | M0 已做 |

释义按界面语言挑（千语集的释义是 `{zh, en, …}` 多语言文字），界面是中文就先显示中文，
没有中文再显示英文。

## 四、同一套模块，日语和人造语言各填什么

| 模块 | 日语 | 千语集来的语言 |
|---|---|---|
| 字母课 | 五十音 | 自造文字，或字母与发音 |
| 词典里「字」那一栏 | 汉字 | 语素 |
| 注音 | 振假名 | 国际音标 |
| 等级 | JLPT N5–N1 | 按词频自动分 3–5 级 |
| 朗读 | Windows 自带的日语语音 | 系统语音读 IPA，或者自己的录音 |
| 视听、考试 | 有 | 没有 |
| 逐词对译、词源 | 没有 | 有 |

界面里没有任何地方判断「这是不是日语」，只看学习包的能力（`PackFeatures`）。

## 五、已定与待定（2026-09-23）

1. **纯欣赏副本：拒收。** 提示学习者向作者要原项目文件。
2. **等级：按词频自动分**（`lib/packs/qonlang/levels.ts`，导入时算好存进 `levels.json`）。
   - 用千语集自己的认词（`analyzeSentence`）数这门语言的例句和短语里每个词条出现几次；
     确认过的分析直接用，复合词里挂的几个词条各算一次。分析在拷贝上做，项目本身不动。
   - 出现多的排前面；次数一样（包括没出现过的）再看它派生出了多少别的词，最后短的在前。
   - 不到 60 个词分 3 级，不到 400 个分 4 级，再多分 5 级；一级最少、越往后越多（1 : 2 : 3 : …）。
   - 词头里一个字母都没有的词条（占位用的「·」这类）不分级，也不拿来学。
   - Aelith 分出来是：一级 kaso、nöl、ilen、jat-、sen、ve、mü（例句里各出现 2–4 次），二级 13 个，三级 20 个。
3. **朗读：读 IPA，也支持自己录音。**
   - Windows 自带的每个 SAPI 声音都能按 IPA 读（`PromptBuilder.AppendTextWithPronunciation`），
     完全离线；外语的音会近似成这个声音会发的音。声调字母读不出，读之前拿掉并提示；
     别的读不出的符号系统会报出是哪一个，也拿掉再读。结果按内容缓存。
   - 读 IPA 用哪个声音、语速在「设置 → 朗读」里挑，默认用英语声音。
   - 录音：发音按钮旁可以直接录音，也可以选一个现成的音频文件。录音存在
     `%APPDATA%\qonsona\recordings\<包 id>\`，按千语集的条目 id 命名，重新导入、移除学习包都不会丢。
     有录音时先放录音。
   - 这些录音只在录音人自己的电脑上。作者要把自己的发音发给所有学习者，得随项目文件带走，见第 4 条。
4. **作者端的「学习设置」：千语集多一种导出格式「学习包」（`.qstudy.json`），项目文件不动。** 见第六节。
5. **单独发行**：最后再定。

## 六、作者端的「学习设置」

### 要设置什么

学习软件能自己算的（等级、读音、文字写法、词形）都已经自动了。算不出来的是作者的教学安排：

| 设置 | 现在学习软件只能怎么办 |
|---|---|
| **课程编排**：哪几篇文档是课、按什么顺序、每课叫什么；每课配哪些新词、哪些例句和短语 | 把全部文档按列表顺序当语法课，连「关于这个示例」这种说明也算一课；例句按「出处」字段猜着分组（Aelith 的出处碰巧写成「语法书 · 宾格」，别的项目未必） |
| **不给学习者看的内容**：占位词条、草稿、祖语拟构、作者自己的笔记类文档 | 只能用「词头里没有字母」这种规则去猜 |
| **学习者默认看到什么**：用哪套正字法、默认显示不显示自造文字和 IPA、释义先用哪种语言 | 借用千语集里的「主正字法」「释义语言」，但那是作者编辑时的偏好，不一定适合学习者 |
| **封面与介绍**：学习者打开这门语言时看到的介绍、背景设定、作者寄语 | 没有 |
| **分级微调**：大体按词频，个别词钉在某一级（代词、数词想放一级，例句里却不多） | 只能纯按词频 |
| **作者的录音**：让所有学习者都听到作者本人的发音 | 录音只在录音人自己的电脑上 |

### 定下的做法：千语集多一种导出格式（2026-09-23）

作者到学习者之间原来只有项目文件这一条通道，在学习软件里设的东西只存在设置者自己的电脑上，
所以千语集得改。但不往项目文件里加字段（你定的：不影响原本的项目，实现解耦），而是：

- **千语集 0.12.4**：设置 → 数据 → 导出里多一个「导出学习包」，进单独一页设置每门语言的
  封面（课程名称、Markdown 介绍）、课程（一课挂一篇文档作课文，挑出新词、例句、短语，可拖动排序，
  可按文档一键生成）、隐藏（词条、例句、短语、文档）、级别（个别词固定到第几级）、
  显示（默认正字法、文字、是否显示 IPA）、录音（麦克风、选文件、按文件名批量对应）。
  这些设置按项目 id 存在千语集的数据目录 `study-export/<项目 id>.json`，不进 `.laim.json`；
  换电脑时可以从以前导出的学习包读回。
- **格式**（千语集 `lib/core/studyPack.ts`，随 `npm run sync:qonlang` 进 `vendor/qonlang/core/studyPack.ts`）：
  `{ "format": "qonlang-study-pack", "version": 1, exportedAt, qonlangVersion, study, project }`。
  `project` 就是完整的项目（跟 `.laim.json` 一样），`study.languages[]` 每门语言一份设置，
  录音以 data URL 内嵌，键是 `lexeme-<id>` / `phrase-<id>` / `sentence-<id>`，跟学习软件自己的录音键同一套。
  千语集的「打开项目」不收学习包（报「文件不是千语集项目」）。
- **学习软件这边**（`lib/packs/qonlang/study.ts`、`convert.ts`）：「语言」页照样选文件或拖进来，
  认出是学习包就在导入面板写明，作者没勾导出的语言默认不勾。每门语言的学习包目录里多：
  - `study.json`：作者、课程名称、介绍、课程、隐藏、固定级别、默认显示、有作者录音的条目键；
  - `audio/<条目键>.<扩展名>`：作者录音（data URL 解成文件；只收 webm、ogg、mp3、wav、m4a、flac）。
- **怎么用上**：
  - 名称换成作者起的课程名称（自己的叫法仍是语言名）；卡片与首页写作者；首页显示介绍。
  - 隐藏的词条、例句处处不出现（词典、首页样例），也不参加分级；固定级别的词放到那一级，级数不够放最后一级。
  - 发音：自己的录音 → 作者录音 → 系统语音读 IPA。删掉自己的录音就回到作者录音。
  - 默认文字排在样例最前、`showIpa` 控制样例的 IPA 行；默认正字法和课程等 M2 的阅读、课程模块用。
- 普通项目文件照样能导入，只是没有这些设置（没有 `study.json`）。

## 七、跟进千语集新版本的步骤

1. `npm run sync:qonlang`（取 `../Qonlang` 的 HEAD；指定版本用 `npm run sync:qonlang -- --ref v0.12.3`）。
2. `npm run typecheck`、`npx vitest run`、`npx electron-vite build`、`npm run smoke`，全部通过。
3. 提交时写明从千语集哪个版本同步到哪个版本。
