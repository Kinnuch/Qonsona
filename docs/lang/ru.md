## 一、俄语的特点

### 文字

- 西里尔字母 33 个：10 个元音字母（а э ы у о / я е и ю ё，后五个表示前面辅音软化或带 [j]），21 个辅音字母，
  两个符号 ь（软音符号，表示前面辅音软化；在辅音与元音之间还起分隔作用：семья́ [sʲɪˈmʲja]）、
  ъ（硬音符号，只起分隔作用：съесть [sjesʲtʲ]）。й 是半元音，跟 и 是两个字母（мой ≠ мои）。
- **跟拉丁字母形同音不同**（初学者最容易读错）：В [v]、Н [n]、Р [r]、С [s]、У [u]、Х [x]、Е [je]、
  小写 и [i]（像拉丁 u 倒过来）、п [p]、т [t]（手写体 т 像 m）、г [g]（手写体像 z）、д（手写体像 g）。
  只有 А К М О Т 读得跟拉丁字母差不多。网上的文本里偶尔混进拉丁形近字母（мaмa 里的拉丁 a），查词键会换掉。
- **ё 平常写成 е**：词典、课本、儿童读物写 ё，报刊、网页大多不写；ё 永远重读，写成 е 时读者自己补。
- 1918 年以前的旧正字法（ѣ і ѳ ѵ、词尾的 ъ：сѣверъ = север）在公有领域的老书里还会看到，宽松键能对上。

### 发音与拼写

- **重音不标，位置自由，而且会在变格变位里移动**：рука́ — ру́ку — ру́ки；го́род — города́；
  говорю́ — говори́шь（不动）；люблю́ — лю́бишь（移动）。扎利兹尼亚克把名词的重音分成 a（固定在词干）、
  b（固定在词尾）、c、d、e、f（各种移动）几类，词典里写在 `x.stress`，会移动的标 `mobile-stress`。
- **非重读元音弱化**：аканье（о、а 不重读时读 [ɐ]、[ə]：молоко́ [məɫɐˈko]），иканье（е、я 在软辅音后
  不重读时读 [ɪ]：язы́к [jɪˈzɨk]、пятно́ [pʲɪtˈno]）。所以重音错了，元音也跟着读错，拼写跟读音对不上。
- 软硬辅音成对（мат / мать、брат / брать、был / бил）；ж ш ц 永远硬，ч щ 永远软。
- 浊辅音在词尾、清辅音前清化（хлеб [xlʲep]、ло́дка [ˈɫotkə]），清辅音在浊辅音前浊化（вокза́л [vɐˈɡzaɫ]）；
  有些辅音不发音（здра́вствуйте [ˈzdrastvʊjtʲɪ]、со́лнце [ˈsont͡sə]）。
- 拼写规则：г к х ж ш ч щ 后面写 и 不写 ы，ж ш ч щ ц 后面写 а у 不写 я ю（形容词、名词词尾因此分「硬、软、混合」）。

### 形态

- **名词**：阳、阴、中三个性；单复数；六个格——主格、属格、与格、宾格、工具格、前置格（还有残留的第二属格
  ча́ю、第二前置格 в лесу́、计数形 два часа́、呼格 мам）。有生名词的宾格同属格（ви́жу бра́та），无生的同主格。
  按词尾分三种变格法（中国课本的叫法：-а/-я 的第一变格法，阳性零词尾与中性的第二变格法，阴性 -ь 的第三变格法），
  另有异格名词（вре́мя、путь）、形容词式变格的名词（столо́вая、учёный）、不变格的外来词（кофе、метро）、
  只有复数的名词（но́жницы、де́ньги）。复数属格（零词尾 / -ов / -ей）是公认的难点。
- **形容词**：长尾随名词变性、数、格（4 × 6，阳性宾格分有生无生），短尾作谓语（хоро́ш、хороша́）；
  比较级 -ее 与一批不规则的（лу́чше、ху́же、бо́льше、ме́ньше），最高级 са́мый + 原级或 -ейший。
- **代词**都变格（я — меня́ — мне — мной）；**数词**也变格，而且支配名词的格：оди́н 跟名词性数格一致，
  два、три、четы́ре 后接单数属格（два стола́），пять 以上接复数属格（пять столо́в），合成数词看最后一位。
- **动词**：
  - **体**：几乎每个动词都分完成体与未完成体，成对出现（де́лать / сде́лать、говори́ть / сказа́ть、
    брать / взять）。配对的办法：加前缀（с-、по-、на-、про-……）、改后缀（-ыва-/-ива-、-а-/-и-）、
    异根（брать / взять）。完成体没有现在时，现在时的形式表示将来（сде́лаю = 我将做完）；
    未完成体的将来时用 бу́ду + 不定式。
  - **变位**：第一变位法（-ешь、-ут/-ют）、第二变位法（-ишь、-ат/-ят），混合的（хоте́ть、бежа́ть），
    不规则的（быть、есть、дать）；很多动词变位时词干辅音交替（писа́ть — пишу́、люби́ть — люблю́）。
  - 过去时按性、数变（говори́л / говори́ла / говори́ло / говори́ли），不按人称。
  - 形动词四种（主动现在、主动过去、被动现在、被动过去）像形容词一样变格；副动词两种不变。
  - **-ся 动词**：反身、相互、被动、无人称、纯粹的词汇意义（смея́ться）。
  - **运动动词**：十几对定向 / 不定向动词（идти́ / ходи́ть、е́хать / е́здить、лете́ть / лета́ть、
    нести́ / носи́ть、вести́ / води́ть、везти́ / вози́ть、бежа́ть / бе́гать、плыть / пла́вать……），
    再加前缀表示方向（при-、у-、в-、вы́-、под-、от-、за-、пере-、про-、до-、об-、с-），加了前缀就成了体的配对
    （приходи́ть / прийти́）。这是俄语学习的公认难点。

### 句法

- 语序灵活：格表示语法关系，语序表示已知—新信息（Ма́му лю́бит сын. 新信息「儿子」放最后）。
- 没有冠词；现在时省略系动词（Я студе́нт）；拥有用 у меня́ (есть)；大量无人称句（Мне хо́лодно、Мне нра́вится）；
  否定时宾语、主语常用属格（Нет вре́мени）；否定一致（Никто́ ничего́ не сказа́л）；语气词（же、ведь、ли、-то、-ка）。

### 中文母语者的难点

1. **发音**：大舌颤音 р、软辅音（ть дь ль нь）、ы、清浊对立（б/п、д/т、г/к——普通话没有浊塞音）、
   辅音丛（здра́вствуйте、взгляд）、重音位置与元音弱化。
2. **屈折**：中文没有格、性、数的变化，名词、形容词、代词、数词的一致与支配要一个一个记；复数属格；数词支配的格。
3. **体**：「了」跟完成体不对应；什么时候用哪个体、体的配对怎么记。
4. **运动动词**与前缀。
5. 记单词要连重音、性、变格类型、体的配对一起记，不能只记一个词形。

## 二、跟日语的做法哪里该不一样

| 方面 | 日语 | 俄语 |
|---|---|---|
| 注音 | 振假名 / 罗马字 | **不注音**（`features.ruby = null`）；正文的辅助记号是**重音符号**与 **ё 的两点**，阅读时可开关（`rules.marks`：`stress`、`yo`）；词典的带重音写法放 `d`，界面显示 `d`。罗马化只在词典里显示（学术转写），不放进正文 |
| 文字 | 假名、汉字（KanjiVG 笔顺、手写查字） | 33 个字母，没有汉字一栏（`characters = null`）；字母课要讲形近字母、手写体、ь ъ 的作用 |
| 查词 | 写法、读音、罗马字、去活用 | 去重音符号、**ё 写成 е 也查得到**（宽松键）、旧正字法、拉丁形近字母；**变格变位表是查词的根本**（阅读器靠它从 столо́в 找回 стол），表里查不到的（形动词的各格、冷僻词）靠 `lemmaCandidates` 推 |
| 切词 | kuromoji | Intl.Segmenter + 连字符词并回一个（кто-то、по-русски、из-за） |
| 词典里的重点 | 读音、汉字、JLPT | **变格变位表**（带重音）、**体的配对**（`x.aspect`）、性与有生、变格类型、重音类型与重音是否移动 |
| 分级 | JLPT N5–N1 | **ТРКИ 六级**（ТЭУ…ТРКИ-4 = A1…C2） |
| 语法点（阶段二） | 看助词、助动词 | 要看**格、体、时、形动词**这些词形标签（form 表的 `tags`）与介词、语气词；数词后的格 |
| 练习（阶段五） | 读法、写法、语法填空 | **格**（介词 + 格、数词 + 格）、**体**（选体）、**运动动词**、**重音**（选重读位置）、变位 |

### 词怎么分到各级

1. **合成词频名次**（`fr`）：OpenSubtitles 字幕、Tatoeba 句子、维基百科的词形频率按词典的变形表分到词条——
   一个词形对上几个词条时按各词条的总频率比例分（迭代四轮）；专名、字母、缩写不跟普通词分（По、Или、В 不会
   抢走 по、или、в 的次数）；一个词形是某词条的词头、又是别的词条的形动词 / 短尾 / 比较级 / 异体时算给词头那个
   （хорошо́、краси́во 是副词，不是形容词的短尾中性）；Tatoeba 里句中大写的词只算给专名（Том 不算给「том 卷」）。
   再加 OpenRussian 的排名（按 Zipf 换成频率）。合成：各来源每百万次的对数加权平均——字幕 0.3、Tatoeba 0.3、
   OpenRussian 0.25、维基百科 0.15（维基百科权重低，免得 область、район、сезон 这类百科词排得太前）。
2. **定死的等级**：`data/ru/basic.json`（自己整理的 18 个主题、约 400 个基础词：数字、星期、月份、颜色、家人、
   问候、疑问词、代词、食物、身体、城市与场所、交通、学习与工作、天气、国家与语言、常用动词与形容词）
   与 OpenRussian 人工标的 A1 / A2。
3. **按官方词汇量切**：每一级的累计词数照 780、1300、2300、5000、11000、20000，定死的词也算在里面。
   专名、缩写、词缀、符号、谚语不分级（官方大纲不收专名；俄罗斯、中国、莫斯科、北京由 basic.json 定在 A1）。
4. **体的配对最多差一级**：говори́ть 在 A1，сказа́ть 最晚 A2。

**变形表的标签**：名词 `nominative` … `prepositional`、`locative`（в лесу́）、`partitive`（ча́ю）、`vocative`、
`count-form` × `singular` / `plural`；形容词另加 `masculine` / `feminine` / `neuter`、宾格的 `animate` / `inanimate`、
`short-form`（短尾）、`comparative`；动词 `infinitive`、`present` / `future` / `past` / `imperative` × 人称、数、性，
形动词 `active` / `passive` + `participle` + 时，副动词 `adverbial` + `participle` + 时；另有 `alternative`（异体写法）。
存疑的形式（维基词典标 ⟐ ▽、молоко 的复数）、旧正字法的表、分析式将来时（бу́ду говори́ть）不收。

**体积的取舍**：词频前 3 万名与有等级的词收完整的变格变位表；更冷僻的只收主要形式（名词的单数属格与复数主格、属格，
动词的人称形式、过去时与命令式，形容词的短尾与比较级），别的变形靠 `rules.lemmaCandidates` 推；
哪份频率表里都没出现过的实词（6785 个）不收；形动词的各格不收（几十万个），阅读器先推回形动词、再在动词的变位表里找到。

**中文释义**：两部维基词典的中文义项跟英文义项不是一一对应的（义项数相同时次序也常常不同：хоро́ший 的「好看的」
对着中文的「亲密的」），所以中文都放在**第一个义项**上当汇总：先放俄文维基词典译文表里的直接对译
（молоко́ → 牛奶，奶水，乳汁，乳），再接中文维基词典的各条释义（去重）。同形异义词（есть「吃」/ есть「有」、
за́мок / замо́к）两边条数一样时按页面上的先后对齐，对不上的宁可不用。三部维基词典对代词性的词、虚词的词性分法
不一样，本词性对不上时在相近的词性里找。繁体按 OpenCC 转简体。共 22 627 个词条有中文（占 40%；A1 93%、C2 48%）。
没有中文的常用词列在 `data/ru/zh-todo.txt`（前 8000 个；主线的补译流水线 `scripts/lang/mt.ts` 直接从词典挑，这份只作参考）。

**例句**：维基词典的用例（短语、短句，带重音与英译，挂在义项上）；Tatoeba 每个词挑三句：有中文翻译的优先、
20～60 个字母的长度优先、句子不比这个词难太多（最多高一级）、Том 和 Мэри 的句子往后放；再顺手挂给句中例句还不到
8 句的词。例句的 `lv` 是句中最难的词的等级。

**主题词本**：basic.json 的 18 个主题（`theme:<id>`，名字在 `meta.themes`）。阶段三再扩充到 50～300 词一本。

## 六、规则（`src/shared/lang/ru/rules.ts`）

- **查词键**：小写、去掉重音符号（U+0301 主重音、U+0300 次重音，预组合的 ѐ ѝ 也拆开去掉）、**保留 ё**；
  混在俄语词里的拉丁形近字母（a c e o p x y，带重音的 á é ó ý，ë）换成西里尔字母；连字符统一成「-」，软连字符去掉。
  保留 ё 的理由：学习材料都写 ё，保留它查得准（всё 不会混到 все 去）；不写 ё 的文本靠宽松键找回。
- **宽松键**：在查词键上再把 ё → е，旧正字法（ѣ → е、і → и、ѳ → ф、ѵ → и、词尾辅音后的 ъ 去掉）对到今天的写法。
  **й 不动**（框架默认的 stripMarks 会把 й 拆成 и，мой 就成了 мои）。
- **切词**：Intl.Segmenter 会把 кто-то、что-нибудь、по-русски、из-за、Ростов-на-Дону 从连字符处切开，这里并回一个词；
  前后有空格的连字符（当破折号用）不并。
- **猜原形**（form 表查不到时）：形容词与形动词的各格 → 阳性单数一格（拼写规则：г к х ж ш ч щ 后不写 ы）；
  反身的 -ся；短尾被动形动词（сделана → сделанный）；по- 比较级、наи- 与 -ейший 最高级；连字符后的语气词
  （-то、-ка、-таки）与 кое-；规则动词、名词的词尾。最多 40 个。
- **记号**：重音符号、ё 上的两点，都可以开关。
- **转写**：学术转写（scholarly，ISO/R 9:1968 一系）——ж ž、х x、ц c、ч č、ш š、щ šč、ъ ʺ、ы y、ь ʹ、э è、
  ю ju、я ja、ё ë、й j，重音符号带到拉丁字母上（молоко́ → molokó）。选它而不选 ISO 9（щ ŝ、я â 不直观）或
  BGN/PCGN（zh kh ts，为英语读者设计、不可逆）：一字一译、可逆，语言学界通用，х 写 x 正好跟汉语拼音的 h 同音。
- **拉丁字母输入**：`latinToCyrillic()` 把 privet、khorosho、zdravstvuyte、ščuka 这类拼法转回西里尔字母
  （认学术转写、BGN/PCGN 与常见打字习惯；元音后的 y 当 й；词首 e 另给 э）。框架还没接（见「要框架做的」）。

测试：`tests/lang/ru/rules.test.ts`（规则 25 个）、`tests/lang/ru/pipeline.test.ts`（管线的零件 10 个）。

2. **特有字段的叫法**（`dict.lex.extra`）：`zal` 扎利兹尼亚克类型（Zaliznyak class）；`stress` 现在显示成「重音 b」，
   最好写成「重音类型 b（a 固定在词干、b 固定在词尾、c–f 会移动）」。
3. **变形表排成网格**：名词按格（行）× 单复数（列），形容词按格 × 阳 / 中 / 阴 / 复数，动词按人称 × 单复数、过去时按性数——
   现在是一行一组标签；一项带几个格（`nominative accusative`）时两格都填。
4. **拉丁字母输入**：查词框里输入 privet、khorosho 时用 `latinToCyrillic()`（`src/shared/lang/ru/rules.ts` 已导出）转成
   西里尔字母再查，像日语的罗马字。建议 `LangRules` 加一个可选的 `fromLatin?(text): string[]`。
5. **例句里标出这个词**：现在按带重音的变形比，Tatoeba 例句不带重音，标不出变过形的词（молока́ 对不上 молока）；
   比较前先用 `rules.key()` 或 `marks` 去掉记号。
6. **词条列表上的等级**：列表里显示的是等级 id（teu、trki2），词条页的标签显示的是 A1——列表也用 `short`。
7. **中文汇总**：中文都在第一个义项上（见「中文释义」）。补译流水线 `mt.ts` 挑「没有中文的义项」，这样有中文汇总的
   常用词还会把后面的义项送去机译——建议：已经有人写的中文的词条跳过，或者照样译（界面上第一条是汇总、后面是各义项的机译）。
8. **同形词的选择**：阅读器的 `lookup` 按词频取第一个词条；俄语里一个词形常是几个词条的变形（стали：сталь / стать；
   дома：дом / 副词 дома），建议词卡上列出别的词条（像 `alt` 那样）。
