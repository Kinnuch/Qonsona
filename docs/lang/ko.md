## 一、韩语的特点

### 文字

- 韩文字母（한글）：基本字母 24 个（辅音 14：ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ，元音 10：ㅏㅑㅓㅕㅗㅛㅜㅠㅡㅣ），
  另有紧音 5 个（ㄲㄸㅃㅆㅉ）、复合元音 11 个（ㅐㅒㅔㅖㅘㅙㅚㅝㅞㅟㅢ），合计初声 19、中声 21。
- 字母不排成一行，而是拼成**音节块**：初声 + 中声（+ 终声，即收音 받침）。Unicode 里按公式排好了全部
  11,172 个音节（0xAC00 + (初声 × 21 + 中声) × 28 + 终声），程序拆合就靠这个（`hangul.ts`）。
- 收音写法有 27 种（含 ㄳ ㄺ ㄼ 这类双收音），读出来只有 **7 个代表音**：ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅇ。
- 一两天就能学会读，这是韩语对初学者最友好的地方；字母课（阶段四）要讲清初声、中声、收音与音节块的拼法。

### 发音与拼写：写法按词素，读法按音变

韩文按词素写（먹 + 는 写成 먹는），读的时候要过一串音变（标准发音法 표준 발음법），学的人看着字读不对：

| 音变                 | 例                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------ |
| 连音（연음）         | 한국어 [한구거]、읽어 [일거]、값이 [갑씨]                                                  |
| 收音中和、双收音简化 | 옷 [옫]、부엌 [부억]、닭 [닥]、삶 [삼]                                                     |
| 鼻音化（비음화）     | 먹는다 [멍는다]、합니다 [함니다]、국립 [궁닙]                                              |
| 流音化（유음화）     | 신라 [실라]、설날 [설랄]                                                                   |
| 紧音化（경음화）     | 학교 [학꾜]、듣다 [듣따]、신고 [신꼬]（词干末 ㄴ）、할게요 [할께요]、갈등 [갈뜽]（汉字词） |
| 腭化（구개음화）     | 같이 [가치]、굳이 [구지]、닫히다 [다치다]                                                  |
| 送气化（격음화）     | 좋고 [조코]、축하 [추카]、입학 [이팍]                                                      |
| ㅎ 脱落              | 좋아 [조아]、많아 [마나]                                                                   |
| ㄴ 添加              | 솜이불 [솜니불]（要看词素，规则推不出）                                                    |

罗马字（국어의 로마자 표기법，2000）也按发音转写，只是不标紧音：신라 Silla、종로 Jongno、학교 hakgyo。

### 形态：助词与词尾层层黏着

- **体词 + 助词**：학교 + 에서 + 는 → 학교에서는。助词可以叠（에서는、으로부터、까지도、에게서），
  好些按前一个音节有没有收音换写法：이/가、은/는、을/를、와/과、(으)로、(이)나……
- **谓词 = 词干 + 先语末词尾 + 语末词尾**：가 + 시 + 었 + 어요 → 가셨어요。先语末词尾按尊敬 -(으)시-、
  过去 -았/었-、推测意志 -겠- 的顺序叠；语末词尾有终结（-아요、-습니다、-네요）、连接（-고、-아서、-(으)면）、
  转成（-(으)ㄴ、-는、-기、-(으)ㅁ）几类，常用的有一两百个（`endings.ts` 收了 140 多个）。
- 接法分几类：接 아/어 形的（먹어요）、辅音开头直接接的（먹고）、(으) 类（먹으면 / 가면）、成对的（먹습니다 / 갑니다）。
  元音调和：词干末元音是 ㅏ、ㅗ 接 -아，其余接 -어；-았/었- 后面一律 -어。
- **不规则活用**（括号里是词典里这一类谓词的个数）：ㅂ（춥다 → 추워，395）、ㄷ（듣다 → 들어，22）、ㅅ（낫다 → 나아，36）、
  르（모르다 → 몰라，144）、러（이르다 → 이르러，9）、ㅎ（파랗다 → 파래，70）、우（푸다 → 퍼，1）、
  여（하다 → 해，7,915 个 -하다 词）；规则里的脱落：ㄹ 脱落（살다 → 사는、삽니다）、으 脱落（쓰다 → 써）。
  同一形状有规则有不规则（입다 → 입어 / 춥다 → 추워，받다 → 받아 / 듣다 → 들어），学的人只能一个个记。
- **语体（话阶）**：합쇼체（-습니다，最正式）、해요체（-아요，日常礼貌）、해체（-아，平辈、亲近）、해라체（-는다，书面与对下），
  另有已少用的하오체、하게체。**敬语**：主体敬语 -(으)시-（가세요），敬语词汇（드시다、계시다、주무시다、말씀、댁、연세），
  谦语（저、드리다、뵙다）。
- **两套数词**：固有词（하나、둘……아흔아홉）与汉字词（일、이、삼……）；量词决定用哪套：
  개、명、권、마리、잔、살、시（点钟）接固有词，분、원、년、월、일、층 接汉字词。
- **空格（띄어쓰기）**：按语节空格，助词、词尾连写；补助用言、依存名词的隔写很乱（해 주다 / 해주다，할 수 있다）。
  查词的宽松键因此去掉空格（한국 사람 = 한국사람），猜原形时连写的补助用言也拆得开。

### 汉字词

韩语词汇一半以上是汉字词：词典里标了汉字原语的约占七成（기초사전 55,135 条里 39,432 条有汉字写法，含混写的
가능하다 = 可能하다）。对中文母语者是巨大的优势：학교 學校、도서관 圖書館、경제 經濟，看到汉字就懂意思；
读音也有对应（中古汉语的入声 -k/-t/-p 在韩语保留成收音：학 學、일 一、십 十；-t 变 ㄹ：일 一、월 月、발 發）。
所以词典把汉字放进 `x.hanja`，宽松键把汉字转成简体，中文用户输入「学校」就能查到 학교。

## 二、中文母语者的难点

1. **发音**：辅音三分（平音 ㄱ / 紧音 ㄲ / 送气 ㅋ），中文只分送气不送气；收音（ㄱㄷㅂ 不爆破、ㄹ 收音）；
   元音 ㅓ/ㅗ、ㅡ/ㅜ、ㅐ/ㅔ；还有上面那一串音变——这是要在词典与阅读里给「发音提示」的原因。
2. **助词**：은/는（话题）跟 이/가（主语）的区别是公认的难点；에 / 에서、(으)로 的分工；中文没有格标记。
3. **谓词活用**：词尾多、层层叠，不规则要逐个记；该用哪一级话阶、要不要加敬语。
4. **语序**：主宾谓（SOV）、修饰语一律在前（长定语：제가 어제 도서관에서 빌린 책）。
5. **汉字词的「假朋友」**：공부 工夫（= 学习）、애인 愛人（= 恋人）、신문 新聞（= 报纸）、기차 汽車（= 火车）、
   방학 放學（= 放假）、약속 約束（= 约定），看着像、意思不同，词典的中文释义照实际意思写。

## 三、跟日语的做法哪里不一样

|          | 日语                              | 韩语                                                                                             |
| -------- | --------------------------------- | ------------------------------------------------------------------------------------------------ |
| 切词     | 没有空格，靠 kuromoji 形态分析    | 按空格切语节（`tokenize`），语节里的助词、词尾交给 `lemmaCandidates` 剥                          |
| 注音     | 振假名（汉字注读音）              | 不需要振假名（韩文本身是拼音文字），需要的是**发音提示**（标准发音 [멍는]）与罗马字              |
| 汉字     | 是正文的一部分，要注音、要学写    | 正文几乎不用；是词条的附加信息（`x.hanja`），中文用户可以拿汉字（简繁都行）查词                  |
| 还原     | 写死的规则表（`ja/deinflect.ts`） | 正向活用（`conjugate.ts`）+ 倒推候选 + 正向核对（`deinflect.ts`），两边永远一致                  |
| 同形词   | 少                                | 极多（나는 = 나 + 는 / 나다 + -는 / 날다 + -는），要按词频与词性挑（见「规则」与「要框架做的」） |
| 分级     | JLPT N5–N1（N1 最难）             | TOPIK 1–6 级（6 级最难）                                                                         |
| 中文释义 | 机器翻译                          | 한국어기초사전本身有人工中文译文：76,833 个义项里 75,145 个有中文；全库 87% 的词条有中文         |
| 例句     | Tatoeba 带中文                    | 기초사전每个义项都有短语、句子、对话例句（只有韩语）；Tatoeba 带中文的不多（2,537 句）           |

### 公有领域文本（阶段二用，先记录）

- 韩国著作权法：作者在 1963 年以前去世的，著作权已经按旧法（50 年）到期，2013 年延长到 70 年不追溯；
  中国（50 年）也一样是公有领域。可用的作者：김유정（1908–1937）、현진건（1900–1943）、이상（1910–1937）、

## 六、规则（`src/shared/lang/ko/`）

| 文件           | 内容                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------- |
| `hangul.ts`    | 音节拆合；字母串（双收音拆成两个辅音）互转                                                         |
| `pronounce.ts` | 标准发音（上面那张表的音变）；国语罗马字；按词典给的发音转罗马字                                   |
| `endings.ts`   | 谓词词尾表：先语末 3 个、语末 140 多个，各有接法、能接什么词、常用程度                             |
| `conjugate.ts` | 正向活用：类别（规则、ㅂ ㄷ ㅅ ㅎ 르 러 우 不规则、이다），按词典的活用形定类别                    |
| `deinflect.ts` | 反向还原：从词尾往前剥，倒推词干，**每个猜测都用正向活用核对**                                     |
| `particles.ts` | 助词（含收音式缩约 난、이건）、代词特殊写法（내가、제가、뭘）                                      |
| `lemma.ts`     | `lemmaCandidates`：谓词、이다、体词 + 助词、补助用言连写（해주세요 → 하다 + 주다）、带空格的惯用语 |
| `rules.ts`     | `key`、`looseKey`、`tokenize`、`romanize`；`guessFits`（猜原形按词性挑词条，给框架用）             |
| `t2s.ts`       | 汉字繁简对照（`gen-t2s.ts` 生成）                                                                  |
| `spec.ts`      | 分级、能力开关（阶段一只开词典）                                                                   |

- **查词键**：NFC、小写、空白并一个；词缀词尾的连字符留着（-점 不跟名词 점 混）。
  **宽松键**：再去空格与连字符、汉字转简体（學校、学校 → 학교）。
- **切词**：按语节切；数字单独成段（10월 → 10 + 월，好查量词）；拉丁字母间的连字符算在词里（K-pop）。
- **猜原形**：结果按「常见程度」排（谓词分析按词尾常用程度、不规则、缩约加分；名词 + 格助词、代词优先；
  冠形词尾 -는/-(으)ㄴ 跟助词同形的往后排），同一原形的体词式与谓词式分析各留一种。标签是助词、词尾的词典式写法
  （이/가、-았/었-、-아요/어요），이다 写成「이다」，以后认语法点也按它。
- **验证**：
  - 活用引擎跟英文维基词典 4,685 个谓词的活用表（121,627 个形）比对，一致 **99.93%**（差的是维基词典自己的词性标错、
    이다 的写法习惯）。
  - 标准发音跟기초사전 46,366 个词的发音比对，一致 **94.9%**（差的多是要看词素的：汉字词 ㄹ 后紧音、合成词的
    间音紧音化「가을비 [가을삐]」、ㄴ 添加）。词典里的读音用기초사전给的，不靠推。
  - 用기초사전初中级词的 2,810 句例句模拟阅读器：**98.2%** 的句子里有语节被认成该例句所属的词
    （框架照现在的查法；猜原形只认词头行并按词性挑的话 98.4%，见「要框架做的」）。
  - `tests/lang/ko/`：272 个测试（字母拆合、发音与罗马字、每类不规则与常用词尾、助词组合、이다、往返检查：
    24 个代表谓词 × 全部词尾序列，活用出来的每个形都能还原）。

## 七、词典数据库（`resources/data/ko/dict.sqlite`）

`node scripts/data/run-ts.mjs scripts/data/ko/build.ts`（约 30 秒；第一次要下载约 120 MB 原始数据）→
`node scripts/data/run-ts.mjs scripts/lang/validate.ts ko` 合格。另有 `scripts/data/ko/gen-t2s.ts` 生成繁简对照（换词典版本后跑）。

- **100.3 MB**；词条 **68,687**（기초사전 55,135 + 维基词典另立 13,552）；查词键 490,813（其中汉字写法 65,770）；
  例句 163,962（기초사전 152,543 句，只有韩语；Tatoeba 11,419 句，带中文的 2,537、其余带英文）。
- 词性：名词 41,301、动词 11,510、形容词 3,086、副词 2,959、惯用语 2,227、短语与语法表现 2,190、专名 1,959、
  词缀词尾 1,017、冠形词 903、俗语 692，其余几百个。
- 有中文释义 54,869 条（87%，全部出自기초사전人工译文；没有的多是维基词典另立的词条，交给主线补译）、
  有标准发音 46,365 条、有 IPA 约 3.4 万条、有变形表 14,870 条（谓词全部）、有汉字 39,432 条、几乎全部有罗马字。
- 字段约定：
  - `ipa`：第一项是기초사전的标准发音（韩文写，带长音记号：`[학꾜]`、`[사ː람]`），后面是维基词典的 IPA。
  - `rom`：国语罗马字（按기초사전的发音推，紧音不标）。
  - `f`：变形表，`[写法, ...标签]`，标签是词尾的词典式写法（`-았/었-`、`-아요/어요`）；常用谓词（TOPIK 1–4 级、
    기초사전初中级、词频前五千）收全表（约 45 个形），其余收核心的 13 个与词典给的活用形；核心形式连另一种写法
    （돼요 / 되어요）一起收。体词的 `f` 只有跟别的写法同形、要按词频比的几个（우리는、내가）。
  - `fi`：变形的读音，写法跟读法不一样的才写（먹었어요 `[머거써요]`、먹고 `[먹꼬]`、읽는다 `[잉는다]`）。
  - `cls`：活用类别（ㅂ 불규칙、ㄷ 불규칙、ㅅ 불규칙、르 불규칙、러 불규칙、ㅎ 불규칙、우 불규칙、여 불규칙、
    ㄹ 탈락、으 탈락），依存名词、补助用言也标上（의존 명사、보조 동사、보조 형용사）。
  - `x.hanja`：汉字写法（學校；混写的照原样：可能하다；几种写法用 / 隔开：計劃/計畫）。
    `x.origin`：外来语的原文（bus）。`x.krdict`：기초사전的词条号（以后可做成「在기초사전查看」的链接）。
  - 义项：`zh`（기초사전的中文对应词、中文解释）、`en`（英文对应词；没有对应词的才收英文解释句）、
    `mono`（韩语释义、用法说明、句型「문형: 1이 2를 듣다」）、`t`（口语、书面、贬义……）、`syn` / `ant` / `see`。
  - 例句：기초사전每个义项，常用词收 2 个短语、2 句、1 段对话，其余 1 句；对话两行用「가: / 나:」加换行。
- 同形词的取舍（阅读器先在 form 表里对整词，几个词条对上时按词频挑）：
  - 谓词变形跟别的词原形同形（그런데 / 그렇다、하지만 / 하다、아니 / 알다、높임 / 높이다）时比一比哪个更可能，
    那个词占上风就不把这个形放进谓词的变形表（933 个；还原规则照样认得出谓词）。
  - 常用体词加格助词跟谓词变形或冷僻词头同形的（우리는 / 우리다、수가 / 수가），代词特殊写法（내가 / 내가다），
    收进体词的变形表（384 个），按词频比。
- `data/ko/zh-todo.txt`：没有中文释义的常用词 2,000 多个（词头、词性、英文释义）。按 lang-kit 的新约定主线用
  `scripts/lang/mt.ts` 补译，这个文件以后可以不维护。

## 十、要框架做的

1. **猜原形时只认词头行，并按词性挑**（`src/main/lang/lexdb.ts` 的 `lookup()` 与 `search()`）：现在猜出原形后
   `rows(key(g.lemma))` 也会对上**别的词条的变形**——「안에」猜出「안」，对上的是 알다 的变形「안」；
   建议猜原形只认 tags 含 `lemma`（或 `hanja`、`alternative`）的行，再用 `rules.guessFits?.(g.tags, entry.p)` 筛词性
   （韩语的实现已在 `ko/rules.ts` 导出 `guessFits`：助词标签配体词、词尾标签配谓词）。`LangRules` 要加这个可选字段。
   模拟结果：阅读认对率 98.2% → 98.4%，「안에 → 알다」「편이 → 펴다」这类明显的错没了。
2. **前缀搜索只在原形行上找**：变形行太多，查「집」会冒出 지다（집니다 的前缀）。
3. **x 字段的叫法**：`origin`（原语）、`krdict`（한국어기초사전词条号，最好做成链接
   `https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=<号>`）。
4. **韩语标签的说明**：变形与猜原形的标签是词尾、助词的词典式写法（`-아요/어요`、`은/는`），现在原样显示；
   建议加一个 `LangModule.tagLabel?(tag, locale)` 钩子，韩语给每个词尾一句中英说明（「-아요/어요：해요体，日常礼貌」）。
   `cls` 的韩语术语（ㅂ 불규칙……）也可以走这个钩子给中文叫法。
