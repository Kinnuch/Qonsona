## 一、这门语言的特点

### 文字

- **从右往左、连写的辅音字母（abjad）**：28 个字母，每个字母按在词里的位置有独立、词首、词中、词尾四种形状
  （ع ‎عـ ‎ـعـ ‎ـع）。**ا د ذ ر ز و 六个字母不跟后面的字母相连**，所以一个词常断成几段（دَرَسَ 三个字母都不连）。
  靠点区分的字母成组出现（ب ت ث ن ي、ج ح خ、د ذ、ر ز、س ش、ص ض、ط ظ、ع غ、ف ق）。
- **短元音不写**：开口符（فَتْحَة a）、齐齿符（كَسْرَة i）、合口符（ضَمَّة u）、静符（سُكُون，无元音）、
  叠音符（شَدَّة，辅音加倍）、鼻音符（تَنْوِين，词尾 -an -in -un）平时都不写，只在古兰经、儿童读物、教材、诗歌里全标，
  一般文本只在容易误读的地方标（被动态、叠音）。**读阿拉伯语靠认词，不是靠拼读**：كتب 可以是 kataba（他写了）、
  kutiba（被写了）、kutub（书，复数）、kattaba（让人写）。
- **hamza（ء）的写法**：按前后的元音坐在 alif（أ إ）、waw（ؤ）、ya（ئ）上或单独写（ء），alif 上加 madda 是 آ（ʾā）。
  词首的连读 hamza（هَمْزَة الْوَصْل，ٱ）在连读时不发音（冠词 al-、第七到第十式动词、اِسْم 等）。
- **ة（ta marbuta）**：阴性词尾，停顿时读 -a，后面跟正次（属格名词）或带格尾时读 -at。**ى（alif maqsura）**：
  词尾读 ā 的 alif，写得像不带点的 ya。民间书写常把 ة 写成 ه、ى 跟 ي 混用、alif 上的 hamza 省掉——查词要容得下。
- **数字**：东部用阿拉伯-印度数字 ٠١٢٣٤٥٦٧٨٩，马格里布用 0–9；数字在从右往左的行里照样从左往右写（双向文字）。
  标点是反过来的 ، ؛ ؟。延长线 ـ（tatweel / kashida）只为排版拉长，不是字母。

### 发音

- **辅音**：咽音 ح ع、小舌音 ق خ غ、喉塞音 ء、齿间音 ث ذ ظ；**强调音**（咽化）ص ض ط ظ 跟普通的 س د ت ذ 成对，
  还影响旁边的元音。辅音长短（叠音）、元音长短（a/ā、i/ī、u/ū）都区别词义。
- **太阳字母与月亮字母**：冠词 الْ 在 ت ث د ذ ر ز س ش ص ض ط ظ ل ن 前同化（الشَّمْس ash-shams「太阳」），
  在别的字母前照读 al-（الْقَمَر al-qamar「月亮」）。
- 重音位置可以从音节结构推出来，不标；停顿时去掉格尾（كِتَابٌ → kitāb）。

### 形态

- **词根 + 词型**：大多数词由三个根字母（少数四个）套进词型构成。ك ت ب「写」：كَتَبَ 写、كِتَاب 书、كَاتِب 作者、
  مَكْتَب 办公室、مَكْتَبَة 图书馆、مَكْتُوب 写好的。传统词典（汉斯·维尔等）按词根排，查词先得认出词根。
- **动词**：第一式（原形）加九种常用派生式（II–X，另有罕见的 XI–XV 与四母动词 Iq–IVq），各有固定的词义倾向
  （II 使动 / 加强、V 是 II 的反身、VII 被动、X 请求……）；过去式（完成体）与现在式（未完成体），现在式又分
  陈述、虚拟、祈使（切格）三种语气，另有命令式；主动、被动靠元音交替区分；人称分 13 种（含双数）。
  弱动词（带 hamza、叠音、首弱、中弱、尾弱、双弱）的变位各有规律。第一式的过去式、现在式元音（kataba / yaktubu）要逐个记。
- **名词**：阳性 / 阴性（多以 ة 结尾）；单数、**双数**、复数——规则复数（阳性 -ūna/-īna、阴性 -āt）与**破碎式复数**
  （كِتَاب → كُتُب、مَدْرَسَة → مَدَارِس，只能逐个记）；集合名词与单个名词（شَجَر 树木 / شَجَرَة 一棵树）。
  三种状态：不定、定指（الْ）、正次（construct，后面跟属格名词）；三个格（主格、宾格、属格），格尾（إِعْرَاب）
  平时不写，正式朗读、新闻播报、古兰经里才读出来；全变尾（triptote）与半变尾（diptote）的格尾不同。
- **附着词**：前附 وَ「和」、فَ「于是」、بِ「用、在」、كَ「像」、لِ「为了」、سَ「将要」、冠词 الْ（لِ + الْ 写成 لِلْ），
  后附人称代词（名词后是「……的」，动词、介词后是宾语）：وَبِكِتَابِهِمْ = 和 + 用 + 书 + 他们的。一个书面词常是几个词。
- **派生名词**：动名词（مَصْدَر）、主动名词、被动名词、时空名词（مَفْعَل）、工具名词（مِفْعَال）、比较级（أَفْعَل）、
  从属名词 / 关系形容词（ـِيّ nisba：عَرَبِيّ「阿拉伯的」）。

### 句法

- 动词句（谓语在前，VSO）与名词句（SVO；现在时不用系动词：الْكِتَابُ جَدِيدٌ「书是新的」）。
- **正偏组合（إِضَافَة）**：كِتَابُ الطَّالِبِ「学生的书」，正次不带冠词、不加鼻音，偏次用属格。
- 形容词在名词后，性、数、格、定指都要一致；**非人的复数按阴性单数一致**（الْكُتُبُ الْجَدِيدَةُ）；
  动词在复数主语前用单数。数词 3–10 跟名词「性别相反」、11–99 后接宾格单数、100 以上接属格单数——出了名的难。
- **标准语与方言并存**（diglossia）：书面、新闻、正式场合用现代标准语（الْفُصْحَى），日常口语是各地方言
  （埃及、黎凡特、海湾、马格里布、伊拉克……），彼此差别很大。本软件教标准语，方言的词条照收但不分级。

### 中文母语者的难点

1. **书写与认读**：从右往左、连写变形、靠点区分的字母；**不写元音**，读的时候要靠词汇与语法把元音「补」出来——
   这跟汉语、日语假名都完全不同，初期非常依赖带元音的材料。
2. **发音**：咽音 ح ع、小舌音 ق غ خ，强调音与普通音（س/ص、د/ض、ت/ط、ذ/ظ）的对立，ه / ح / خ 的区别，喉塞音 ء，
   颤音 ر，叠音与长元音，词尾辅音与辅音连缀。
3. **形态**：词根词型的构词法对中国学生很陌生；破碎式复数要逐个记；动词 13 个人称 × 时态语气 × 主被动，
   加上十种派生式、各类弱动词；性、数（含双数）、格、定指的一致。
4. **查词**：书面词带着附着词（وبكتابه），变位后的词跟原形相差很远（قُلْتُ ← قَالَ），传统词典又按词根排。
5. **语言环境**：标准语没有人当母语说，影视、日常对话多是方言。

### 跟日语的做法哪里该不一样

| 日语 | 阿拉伯语 |
|---|---|
| 注音：汉字上注振假名 | **元音符号的显示 / 隐藏**（正文本来就可能带或不带元音）+ 拉丁转写；词典给每个词条存带元音的写法 `d` |
| 查词：去活用词尾找原形（kuromoji） | **去元音符号、统一字形**作查词键；**剥附着词**（前附连词介词冠词、后附代词）；冷僻词的变位按词缀猜 |
| 汉字页签：按汉字看词 | **词根**：每个词条带 `x.root`，查「ك ت ب」（字母间空格）列出整个词族；`x.pattern` 是词型 |
| 变形表：动词、形容词的活用 | 动词 80–140 格、名词 27 格以上的变位变格表，体积要控制（见「三」） |
| 从左往右 | **从右往左**，夹着数字、拉丁字母时是双向文字 |
| 分级：JLPT 有现成词表 | 没有开放的官方词表：按词频切 CEFR，规模参照 Kelly 项目，另设 ACTFL 十一个小级 |
| 中文释义：Tomoshi 开放数据 | 没有开放的阿汉词典：中文维基词典 + 维基词典翻译表，不够的列进 zh-todo 等主线机器翻译 |
| 系统有日语语音 | 这台电脑**没有阿拉伯语语音**：靠维基共享资源的真人录音（A1 词 31% 有）与 IPA；系统语音写 `ar-SA`，界面提示去装 |

## 二、规则（`src/shared/lang/ar/`）

`rules.ts`（查词、切词、猜原形、记号、转写）与 `morph.ts`（词根类型、派生式词型、按词根推词型）都是纯函数，
测试在 `tests/lang/ar/`（rules 73 个、morph 23 个、pipeline 9 个，共 105 个）。

- **`key`（查词键）**：NFKC（连字 ﻻ ﷲ 拆开）→ 去掉双向控制符、延长线 → 统一字母（ٱ→ا、波斯语键盘的 ک ی ە → ك ي ه、
  ى + hamza → ئ）→ 阿拉伯-印度数字换成 0–9 → **去掉全部元音符号**（开口、齐齿、合口、静符、叠音、鼻音、短 alif、
  古兰经诵读记号）→ 拉丁字母小写。**保留** hamza 的座位、ة/ه、ى/ي 的区别（这些是正字法本身）。
  这样不带元音的输入、带元音的正文、半带元音的写法都落到同一个键上；带元音的写法放在词条的 `d` 与 form 表的 `form` 列。
- **`looseKey`（宽松键）**：再把 أ إ آ 并成 ا、ى 并成 ي、ة 并成 ه（不规范的书写、输入法）；拉丁转写去掉长音符、
  下加点、ʿ ʾ 与连字符（kitāb、kitab、al-ʿarabiyya → alarabiyya 都能查）。
- **`tokenize`**：Intl.Segmenter 切词后再细分——阿拉伯-印度数字连同小数点 ٫ 算数字；字母跟数字连写的（و١٢٣「和 123」）断开；
  ، ؛ ؟ « » 算标点。**附着词不切开**（跟英语、法语不同：وَالْكِتَابُ 是一个书面词，点击时再拆）。
- **`lemmaCandidates`（猜原形）**：
  1. 剥附着词：[و ف] [ب ك ل س] [ال]（لِ + الْ 的 لل，词干以 ل 开头的 لليل、لله = لِ + الله），后附 ـه ـها ـهم ـهن ـهما ـك ـكم ـكن
     ـكما ـي ـني ـنا；还原接后缀时变了的写法（مدرستها → مدرسة、عليه → على、كتبوه → كتبوا、سماؤه → سماء、رآه → رأى）；
     不定宾格的 alif（كتابا → كتاب）。سَ 只在未完成体前（ي ت ن أ 打头）才剥。
  2. 再按词缀猜变位、变格（冷僻动词的变形表只收了主要形式时靠它）：未完成体前后缀、过去式后缀、命令式，
     派生式与弱动词的还原（يرسل → أرسل、ينكسر → انكسر、يقولون → قال、يرمي → رمى、يصل → وصل、مددت → مد），
     名词的 -ات -ون -ين -ان、阴性 ة。
  候选按剥掉的东西从少到多排；标签用 Wiktextract 的词（past、non-past、plural……）加附着词代号（`CLITICS`：
  conj-wa、prep-bi、definite、pron-3ms……，表里有阿、中、英说明）。
- **`marks`**：`harakat`（去掉元音符号，保留叠音符）、`shadda`（去掉叠音符）两个开关。
- **`romanize`**：简化的学术转写（大体是 ALA-LC / DIN 31635）：ث th、ج j、ح ḥ、خ kh、ذ dh、ش sh、ص ṣ、ض ḍ、ط ṭ、
  ظ ẓ、ع ʿ、غ gh、ق q、ء ʾ（词首不写）；长元音 ā ī ū；叠音写两遍；冠词 al- 与太阳字母同化（ash-shams）；
  词尾 ة 读 -a、带格尾或在正偏组合里读 -at（munaẓẓamat at-taḥrīr）；关系形容词 -ī（ʿarabī）。带元音的写法转得准，
  **不带元音的只能转出辅音与长元音**（كتاب → ktāb），所以阅读器转写要用词典里带元音的形式（见「十、要框架做的」）。
  跟维基词典自己的转写对了 25,606 个词头，4.4% 不同，多是两套写法本身的差别（ʔ/ʾ、ḵ/kh、外来词的元音长短）。
- **`morph.ts`**：词根类型（健全、带 hamza、叠音、首弱、中弱、尾弱、双弱、四母）；各派生式的过去式、现在式、
  动名词、分词词型与意义说明（`VERB_FORMS`）；`wazn()` 按词根推带元音的词的词型（كِتَاب + ك ت ب → فِعَال，
  اِسْتِخْدَام → اِسْتِفْعَال），推不准的（弱字母当长元音、叠音写成一个）不给；`CLS_NAMES` 是各代号的中英文叫法。
  术语：本软件把根字母（جَذْر）叫「词根」，مَصْدَر 叫「动名词」（中文教材常把 مَصْدَر 也叫「词根」，这里不这么叫，免得混）。

### 词条里的字段

- `w` 不带元音的写法（页面标题），`d` 带元音的写法，`rom` 本软件的转写，`ipa`、`au`，`g`（名词的性），`fr` 词频名次。
- `s[].en` 维基词典的英文释义**原样**（主线的机器翻译拿它当键，之后不改写）；`s[].t` 语域、地区、及物性等标签；
  `s[].dom` 维基词典的主题分类；`s[].syn` `ant`；`s[].ex` 维基词典用例。
- `f` 变形表（标签用 Wiktextract 的词；动名词标 `verbal-noun`；动词只标 `past` / `non-past`，主动不标、被动标 `passive`）。
- `cls`：派生式 `form-i` … `form-ivq`；动词的词根类型 `sound` `hamzated` `geminate` `assimilated` `hollow` `defective`
  `doubly-weak` `quadriliteral`；名词的派生类型 `verbal-noun` `active-participle` `passive-participle` `noun-of-place`
  `instance-noun` `elative` `tool-noun` `occupational-noun` `color-defect-adjective`、`nisba`；变格 `triptote` `diptote`
  `invariable`；复数 `broken-plural` `sound-plural`。叫法在 `morph.ts` 的 `CLS_NAMES`。
- `x`（阿拉伯语特有）：`root` 词根（「ك ت ب」，字母间一个空格）；`pattern` 词型（名词按词根推的 وَزْن，动词是派生式的过去式词型）；
  `form` 动词派生式（I … X、Iq …）；`vowels` 第一式的元音（a~u = kataba / yaktubu）。
- 查词键里另有：`tags = 'root'` 的行（键是「ك ت ب」：按词根查词族）、`romanization`、`alternative`（别的念法、异体写法）。

### 变形表收多少（体积）

全收的话查词键 150 万行、库 160 MB。现在：**分级里的 9,000 个词收全表**（动词的被动只收第三人称，第一、二人称的被动几乎不用），
**冷僻动词只收主要形式**（过去式与现在式的他、她、他们、我，现在式的我们，命令式的你，分词与动名词），**冷僻名词、形容词只收主格**；
别的形式查词时靠宽松键与按词缀猜。名词表去掉了维基词典表头带进来的残留标签（复数一栏的 broken-form / sound-form、性），
复数类型改从分类看。

### 词频怎么算（归到原形上）

wordfreq 的阿拉伯语大表是**词形**的频率（والكتاب、كتابه 各算各的），而且不带元音（كتب 可以是 كَتَبَ、كُتُب、كُتِبَ）。
`freq.ts` 把前 30 万个词形逐个分析——查词键、宽松键、剥附着词（冠词、بِ、كَ 只接名词类，سَ 只接动词）——对上几个词条的按先验分：

- 先验 = 词性（虚词 2、普通词 1、专名 0.5、只在方言古典里用的 0.2、字母符号 0.02）×（只对上这个词条的词形的频率
  + Tatoeba 按英译分辨出来的次数 + 虚词词头本身的频率 + 动词的动名词与分词独有的频率的一半）；
- 虚词（في、من、على、أنت）与专名（محمد、أحمد）**占住自己的写法**：同形的别的词的变位只分到 5%；
- 只分一遍，不迭代（迭代会让跟高频虚词同形的冷僻词越分越多）；
- Tatoeba：一个词形对上几个词条时，看哪个词条的英文释义词出现在英译里（IDF 加权；句中只对上一个词条的词，它的释义词算「有主了」；
  几个候选共有的释义词按各自的独有证据平分；只用 12 个词以内的句子）。

按频率算，词形里 25.6% 只对上一个词条、68.1% 对上几个（按上面分）、6.3% 没对上（人名、外文、方言写法、错字）。
排名用的分数 = wordfreq 每百万词出现次数 + 0.25 × Tatoeba 每百万词出现次数（Tatoeba 多是日常会话），
日常主题的具体词（身体、衣服、颜色、食物、家人、职业、动物、时间、天气……按维基词典的主题分类）再乘 3——
新闻、百科语料里这类词偏少，Kelly 项目也是按词频排了再把它们人工补进低级别。

**已知的局限**：不带元音的同形词只能按证据分，个别会偏（比如比较级 أَحْمَد「更值得称赞」借了人名 أحمد 的频率在 A1 里；
مَكَّنَ 借了 يمكن 一部分）。排查用 `AR_EXPLAIN`、`AR_SUSPECTS`。

## 六、中文释义

没有开放许可的阿汉词典，按可靠程度用三层：

1. **中文维基词典的阿拉伯语词条**（来源 `wikt-zh`）：人写的中文释义，按带元音的写法与词性对到词条上，2,565 个词条。
   义项跟英文版对不齐，所以放成词条最前面的一条中文概括（只有一个英文义项的就并进去），按翻译表的译词调整顺序（كتاب 先「书」）。
2. **维基词典翻译表**（来源 `wikt-tr`）：同一个英语义项下的阿语译词与汉语普通话译词；阿语词条有一个义项的英文释义正好是这个英语词时，
   才把汉语译词挂到那个义项上（9,229 个词条有）；中文版汉语词条的翻译表（汉语词 → 阿语译词）补了 452 个词条。
   译词是维基词典编者写的，但阿汉是本软件按英语义项自动对上的，没有逐条人工核对（来源说明里写明了）。
3. 都没有的：列进 **`data/ar/zh-todo.txt`**（前 8,000 个，按词频名次；一行：不带元音的词头 \t 带元音的写法 \t 词性 \t CEFR \t 英文释义，
   义项之间用 | 隔开），等主线的机器翻译补（`mt-` 开头的来源）。

## 十、要框架做的

1. **标签与代号的叫法**：TAG_LABELS 里没有阿拉伯语用到的 `non-past`（现在式）、`paucal`（少数复数）、`collective`（集合名词）、
   `singulative`（单个名词）；`cls` 的代号（派生式 `form-i`…、词根类型 `sound` `hollow`…、名词派生类型 `noun-of-place`…、
   `triptote` `diptote` `invariable` `broken-plural` `sound-plural` `nisba`）；猜原形时附着词的代号（`conj-wa` `prep-bi` `definite`
   `pron-3ms`…）。建议 `LangModule` 加一个 `labels?: Record<string, LocalizedText>`，每门语言自己给；阿拉伯语的现成在
   `morph.ts` 的 `CLS_NAMES` 与 `rules.ts` 的 `CLITICS`（有阿、中、英）。x 字段的叫法：`form`（派生式）、`vowels`（第一式元音）。
2. **词根页签**（`characters: 'roots'`）：一个词根的词族——按 form 表 `tags = 'root'`、键是「ك ت ب」的行取词条，按 `x.pattern`、
   `cls` 分组（动词按派生式排，名词按派生类型）；词条页的词根做成链接。查三个字母的词时顺带提示「词根 ك ت ب 的词族」。
3. **带元音的输入排序**：查询或正文带元音符号时，form 表里 `form` 的元音跟输入对得上的排前面（كُتُب 先出 كِتَاب 的复数，كَتَبَ 先出动词）。
4. **阅读器**：正文 `dir="rtl"`；`marks` 的两个开关；注音用对上的那个词形（form 表的 `form`，带元音）转写，不用正文本身
   （不带元音的正文只能转出 ktb）；点词时把 `LemmaGuess.tags` 里的附着词拆开显示。
5. **字体**：阿语正文、词头要够大（元音符号很小），字体栈建议 Noto Naskh Arabic / Amiri / Scheherazade New（OFL，可以随软件带）
   再到系统的 Segoe UI、Arial、Traditional Arabic。
6. **输入**：很多中国学习者没装阿语键盘——词典输入框旁放一个屏幕键盘（28 个字母、hamza 各种写法、ة ى、元音符号）；
   拉丁转写查词已经能用（kitab）。
7. **录音**：维基共享资源要带说明性的 User-Agent（浏览器 UA 会被 429），下载慢（约 120 KB/s），要缓存。
8. **系统语音**：这台电脑没有阿语语音，界面提示安装「阿拉伯语（沙特阿拉伯）」语音包（spec 写的是 `ar-SA`）。
9. **以后的题型**（阶段五）：找词根、看词型猜意思、破碎式复数、标格尾、一致关系。
