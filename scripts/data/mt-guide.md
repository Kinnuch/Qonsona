# 日语词条释义：英译中规范

你在给一个面向中文母语者的日语学习词典补中文释义。原始数据是 JMdict 的英文释义。

## 输入与输出

输入文件 `.cache/mt/in/part-NNN.tsv`，每行一个词条，制表符分隔四栏：

```
1358280	食べる	たべる	[v1,vt] to eat ‖ [v1,vt] to live on (e.g. a salary); to live off; to subsist on
```

- 第一栏词条号，第二栏词头，第三栏读音，第四栏是用「 ‖ 」隔开的义项；每个义项开头方括号里是词性标记，后面是用分号隔开的几条英文释义（同义的几种说法）。

输出文件 `.cache/mt/out/part-NNN.tsv`（NNN 与输入相同），每行一个词条，制表符分隔两栏：

```
1358280	吃 ‖ 靠……生活；以……为生
```

- 第一栏词条号；第二栏是中文释义，**义项个数必须和输入完全一样**，按顺序用「 ‖ 」（空格 + U+2016 + 空格）隔开。
- **每个输入词条一行，顺序与输入相同，一个都不能少**。不要输出词头、读音、词性。

## 怎么译

1. **简体中文**，词典释义的写法：简短、准确，不写成句子，不加句号。
2. 一个义项里几条英文是同义说法：合并成一到三个中文说法，用全角分号「；」隔开；意思重复的只留一个。
3. **以英文释义为准**，参考词头、读音和词性判断具体指什么，但**不要**凭自己对日语的知识增加英文里没有的意思，也不要删掉英文里有的意思。
4. 动词不要译出 “to”：`to eat` → `吃`；`to be surprised` → `吃惊；惊讶`。
5. 英文括号里的补充说明译成中文放进全角括号：`to raise (a wage)` → `提高（工资）`；`(e.g. a shelf)` 这类举例可以译成「（如：架子）」，太啰嗦的可以省略。
6. 英文里用 something / someone 表示的空位，中文用「……」：`to show someone (into a room)` → `把……领进（房间）`。
7. 助词、助动词、语法词：英文多半是说明（`indicates direct object of action`），译成说明：`表示动作的直接宾语`。接续用法按中文连词译（`and` 作接续助词时译「而；并且」，不要译成并列的「和」）。
8. 拟声拟态词：按英文说明译，可以加「（拟声）」「（拟态）」开头，例如 `（拟态）闪闪发光`。
9. 外来语（片假名词）：译**意思**，不音译（`テーブル` → `桌子；餐桌`）；专有名词、品牌、人名才音译或保留原文。
10. 数量、单位、专有名词里的数字和拉丁字母照抄。
11. **小心同形异义**：日语汉字词的意思可能跟中文字面不同（手紙 ≠ 手纸，勉強 ≠ 勉强），一律按英文意思译，不要照抄日语汉字。
12. 英文本身是缩写或符号的（如 `CD`、`DNA`）照抄。
13. 实在没法译的（英文就是一个外文专名），照抄英文。
14. 译文里不要出现制表符和「‖」。

- 按分配给你的份数，逐份处理：用 Bash 的 `cat` 读一份输入（一份最多约一万两千字，一次能读完），译完立刻用 Write 写出对应的输出文件，再读下一份。不要一次读很多份。
